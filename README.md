# Simulação do Impacto da Adoção de Energias Renováveis em Ambientes de Trabalho

Este projeto simula o impacto da instalação de um sistema de energia solar 
em um ambiente corporativo, estimando:
- Geração de energia (kWh)
- Economia financeira anual
- Redução de CO2
- Participação renovável no consumo total

## Estrutura do Repositório
📁 data/  
Contém o arquivo de dados de consumo energético (consumo_mensal.csv)

📁 src/  
Contém o código Python usado na simulação (simulacao_renovavel.py)

📁 resultados/  
Pasta opcional para armazenar gráficos ou saídas do código.

## Como Executar

1. Instale as dependências:
   pip install pandas

2. Execute o script:
   python src/simulacao_renovavel.py

Os resultados aparecerão no terminal.

## Objetivo Geral
Desenvolver uma solução ligada ao futuro do trabalho, demonstrando como
a adoção de energias renováveis pode tornar ambientes corporativos mais 
eficientes e sustentáveis.
